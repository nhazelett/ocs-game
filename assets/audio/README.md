# Sound cues

Four original, gently enveloped mono PCM cues, synthesized by `python3 tools/audio/generate_cues.py` using Python's standard library. No sampled recordings, voices, third-party compositions or generated-model audio. Each file is under one second, with a peak below full scale. Defaults to 50%; Menu → Sound offers volume, mute and a preview. Settings persist in Godot's user-data directory.

The source and waveforms are MIT licensed under the adjacent LICENSE.txt. They are capability/event signals rather than music: rising notes for a new morning, two soft knocks for a new visitor, descending notes for a known shortfall, and a bright pair for an accepted award. All events retain their visible labels. Sound never supplies knowledge the Sim withholds.
