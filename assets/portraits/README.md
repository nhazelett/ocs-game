# Tabletop cast

Original fictional faceted character designs, generated by `tools/art/generate_portraits.py`. There are no photo references, real faces, insignia or vendor logos. Appearance is an artistic assignment to a portrait key, not an inference from a name, unit or nationality. All 17 current cast keys have a distinct image; `fallback.svg` is intentionally neutral for an absent or unknown key. Runtime uses the supplied `PersonView.Portrait` reference, including the same Ruiz portrait in the tutorial.

The SVGs are source art and can be regenerated without graphics software. The Windows package contains them beside the fonts; every file in this folder is disclosed in PROVENANCE.md. Project license remains to be decided.
