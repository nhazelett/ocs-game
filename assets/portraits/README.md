# Tabletop cast

Original fictional faceted character designs, generated by `tools/art/generate_portraits.py`. There are no photo references, real faces, insignia or vendor logos. Appearance is an artistic assignment to a portrait key, not an inference from a name, unit or nationality. All 17 current cast keys have a distinct image; `fallback.svg` is intentionally a featureless silhouette for an absent or unknown key. Runtime uses the supplied `PersonView.Portrait` reference, including the same Ruiz portrait in the tutorial.

The SVGs are source art and can be regenerated without graphics software. The Windows package contains them beside the fonts; every file in this folder is disclosed in PROVENANCE.md. Project license remains to be decided.

ART-17 refresh (13 Nov 2026): the named faces have open light eye shapes and dark pupils that remain visible at desk size. The named identities keep their original skin/hair/shirt colours, hairstyle, glasses and beard assignments. `STAGING` in the generator explicitly authors each head tilt, head offset, shoulder stance, collar, expression and gaze; no two named people share the same pose/collar combination. Six collar constructions and six expressions add variety without marks or insignia. Following Fable's review, the fallback stays a featureless silhouette in the current palette and knit collar style; it never assigns a shared face to unrelated people.
