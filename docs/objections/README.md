# Objections

One file per objection, `OBJ-NNNN-short-name.md`, from `TEMPLATE.md`. Rules are in `docs/DISSENT.md`.

This is a folder and not a new ADR status because most objections target something that is not an ADR (a backlog item, a PR, a spec section, a scenario value). When an objection targets an accepted ADR, that ADR's status reads `Contested (OBJ-NNNN)` until the objection is decided. A decision that changes the design is recorded as a new or superseding ADR, and the objection record links it.
