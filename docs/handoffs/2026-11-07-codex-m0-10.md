**Work session handoff**

Expected look of this build and why: five simple sand/olive shapes on a flat plane under one light and a three-quarter orthographic camera. This is the explicit primitive fallback, labeled as such in the screenshot. It is an asset-pipeline experiment, not a polished diorama or playable game.

## Changed

- Added a parameterized bpy generator for tent, CHU, generator, fuel bladder and light truck. Uses flat faces, vertex colors, a shared four-color palette, selected-object glTF exports and provenance updates. No real place names, service marks, textures or third-party art.
- Blender is not installed or on PATH here. The bpy script is syntax-checked but NOT executed or Blender-validated; tools/README.md records this limitation and the intended invocation.
- Exercised the allowed fallback: Godot-generated flat-shaded primitives exported to five actual GLB files under assets/kit, then reloaded into the test scene. Every file is disclosed as generated by Godot, not Blender, in PROVENANCE.md. License remains the project's existing TBD.
- Added a kit validator and a Godot test scene with an orthographic three-quarter camera, one directional light and labels. CI fetches LFS meshes and verifies the kit without needing Blender. Normal gameplay does not invoke generation.

## Why

M0-10 explicitly permits primitive geometry when Blender is unavailable. The fallback proves camera, light, glTF transport, vertex colors and the rough visual direction while remaining honest about the untested bpy path. No missing Sim type or rule is needed.

## Validated how

- Game build and Godot 4.6.1 headless import pass. Kit smoke exports/reloads five glTF files and confirms vertex colors, orthographic camera and exactly one directional light.
- Actual OpenGL screenshot captured and visually inspected; all five pieces are distinct, lit and framed on the plane.
- Python script syntax and the GLB validator pass. The latter requires embedded buffers, positions/normals/COLOR_0 on every primitive and no textures.
- Full .NET Release build/tests and Python tools/validate/validate.py run before opening the PR. No protected component edits. Branch is independently based on main, not on unmerged PR 9 or 10.
